Before we look inside

So, what is Elixir?

In the words of its own website, Elixir is a dynamic, functional language for building scalable and maintainable applications. José Valim started it in 2011 to make Erlang’s runtime easier to use, and it compiles to that same virtual machine, the BEAM.

Three habits

  1. 01Transform data, don’t change it.Values never change in place. Small functions take data in and hand new data out.
  2. 02Split the work into tiny processes.Thousands, even millions of them, each with its own memory, talking only by sending messages.
  3. 03Let it crash.When one process fails, a supervisor restarts it, and the rest of the system keeps running.

Four numbers

2011
José Valim’s first commit
2014
v1.0, with a promise to stay compatible across 1.x
1.20

people online at once on Discord’s Elixir servers (2017)

That mix is why Elixir runs chat, live streaming and connected-device systems. The next chapter shows which habits come from Elixir itself, and which it inherits from the engine. Sources: elixir-lang.org; the paper, Sections 2, 3 and 6.

Getting started

How to install Elixir

The only thing Elixir needs is Erlang, version 27 or later, and most installers bring it along. After that it takes four steps: install it, check it, play with it, then start a real project.

  1. 01

    Install it

    Pick your system and paste the command into a terminal. Each one comes from the official install page.

  2. 02

    Check that it works

    The first line is Erlang’s engine starting up: running Elixir always starts the BEAM. Your version numbers may be newer than ours.

  3. 03

    Play in the shell

    iex is Elixir’s interactive shell: type a line, see the answer straight away. Press Ctrl+C twice to leave.

  4. 04

    Start a project

    Mix, Elixir’s build tool, creates a project with a module and its tests already written. mix test runs them.

That’s all you need to follow along: everything in chapter 03 can be typed straight into iex. Commands: elixir-lang.org/install. Outputs recorded on Elixir 1.20.4 with Erlang/OTP 29.
